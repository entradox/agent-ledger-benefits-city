## Architecture
- Layers touched: data (`types.ts`, `db.ts`, `seed.ts`), domain (`links.ts`, `freshness.ts`, `meta.ts`), transport (`web-server.ts`, `mcp-tools.ts`, `cli.ts`, `site.ts`).
- Ownership: `db.ts` owns storage + servability + ordering; `links.ts` owns apply-URL resolution, public shaping and disclosure wording; `freshness.ts` owns classification (pure); transports only call these.
- Import direction: transports -> domain (`links`, `freshness`, `meta`) -> data (`db`, `types`). `db.ts` imports nothing from domain/transport.
