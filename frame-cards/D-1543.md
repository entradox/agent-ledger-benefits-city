## Context

Red-team batch (PR #1, merged 2026-10-02) left three items:

1. **Rate limiting was deferred** because `clientIp()` needs `TRUSTED_PROXY_HOPS=2`
   (Cloudflare Worker → Railway edge = 2 appends) to resolve the real visitor.
   Without it, every visitor through the main site resolves to the proxy IP and a
   naive limiter would throttle everyone together. Design: ship the limiter OFF by
   default; enabling it is a paired env change with `TRUSTED_PROXY_HOPS=2`.
2. **BMO record** cites a Doctor of Credit post for a different bonus
   ($350 checking / $300 savings) — needs checking against BMO's current offer.
3. `TRUSTED_PROXY_HOPS=2` itself must be set on Railway by the principal (no
   Railway access from this lane).
