## Scope — what this card is and is NOT

**IS:** freeze the offer data contract. Derive the field set from `src/types.ts` and the live
feeds (`/api/bonuses.json`, `/benefits/bonuses/:slug.json`); record for every field its
provenance (source URL + verified date) and its nullability; commit a versioned schema artifact;
add a test that fails when a live offer violates the schema.

**IS NOT:** any visual decision. No card layout, no colour, no font, no logo handling, no copy.
Those belong to tasks 2–7 and are **gated on the design direction**, which is not yet fixed
(see Open, below). A schema card that starts choosing CSS classes has exceeded its frame.

## Why this card exists first

Task 1 is the only item in the rebuild sequence that is specifiable without the design brief,
because it derives from source rather than from a design decision. Every later task (logos +
Card v2, featured, discovery, detail, fonts, P1 cards) consumes the UI spec the missing
deep-dive report was to supply. Freezing the data contract now is the one move that is both
safe and load-bearing later.
